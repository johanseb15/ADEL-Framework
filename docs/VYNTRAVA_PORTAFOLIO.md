## Regla de publicación

- Una **demo** es demostración, no cliente, certificación ni tracción.
- Las métricas reportadas o basadas en fixtures se identifican como tales.
- Una funcionalidad no se declara disponible sin comprobar la versión publicada.
- Las páginas deben enlazar a repositorios, casos documentados y canal de contacto sin exponer información privada.
- El diseño debe tener calidad visual, uso en móvil y accesibilidad verificados; las capturas no sustituyen pruebas.
- La visibilidad de otros repositorios personales se decide en una auditoría interna, fuera del portafolio público. No se enumeran repositorios privados.

## Plantilla para próximos casos

**Problema real → hipótesis → implementación → pruebas → demostración → métricas → limitaciones → siguiente decisión comercial.**

Las métricas mínimas de un piloto vendible deben incluir: tiempo manual previo, tiempo automatizado, precisión sobre muestra auditada, tasa de fallos, esfuerzo de mantenimiento y solicitudes comerciales atribuibles.

**Vyntrava Technologies:** soluciones de software y automatización orientadas a resultados verificables. Este portafolio documenta capacidades de ingeniería; no pretende representar contratos o facturación no acreditados.
